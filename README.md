gardio Desktop App Updates
This repository is responsible for managing updates to the desktop application. It handles version checks, update notifications, and delivery of the latest versions to users. The updates are delivered to users through a secure and efficient process to ensure that they always have the latest features and bug fixes.

Features
Automatic Version Checking: The app checks if a newer version is available for download.
Update Notifications: The app notifies the user when an update is available.
Update Delivery: Secure and efficient delivery of the latest version of the app.
Rollback Support: If an update fails, the app can revert to the previous stable version.
